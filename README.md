# Nsaabo downloads

**Give together. See it arrive.**

Nsaabo keeps a shared, transparent record of contributions for funerals, weddings, churches and organisations in Ghana. It never holds money.

## Install on Android

1. Open the [latest release](https://github.com/OriginalSolution/nsaabo-releases/releases/latest) on your phone.
2. Download `Nsaabo-preview.apk`.
3. Open it and allow installs from this source if Android asks.

Preview builds are for testing. Each release lists its version and the APK's SHA-256 checksum.
